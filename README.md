Информационная система «Музыкальная школа»
Автор: Иванова Елизавета (студентка группы 324, специальность 09.02.07)
Тема курсового проекта: Разработка информационной сети для музыкальной школы

Назначение проекта
Данное приложение представляет собой десктопную информационную систему для автоматизации процессов музыкальной школы. Система позволяет вести учет учеников и преподавателей, управлять каталогом образовательных программ, оформлять заявки на обучение (с автоматическим расчетом скидок) и просматривать расписание учебных групп.

Технологический стек
Язык программирования: C# (.NET 10.0)

Фреймворк интерфейса: Avalonia UI (v12.1.2)

СУБД: Microsoft SQL Server (LocalDB)

Доступ к данным: Entity Framework Core (v10.0.12)

Контроль версий: Git + GitHub

Роли пользователей
В системе реализовано разграничение прав доступа:

Гость (неавторизованный пользователь): может просматривать каталог программ, но не может оформлять заявки.

Ученик: может просматривать каталог и оформлять заявки на обучение.

Преподаватель: имеет доступ к каталогу и может просматривать расписание своих учебных групп (кнопка «Мои группы»).

Администратор: обладает полным доступом. Может просматривать список всех заявок, удалять их, а также видеть все группы школы.

Ограничение учебного входа: В данной версии приложения вход выполняется простым выбором пользователя из выпадающего списка (без ввода пароля). Это сделано для демонстрации работы ролевой модели в рамках курсового проекта.

Состав папок проекта
Assets/ — графические ресурсы (логотип, иконка приложения).

Data/ — контекст базы данных MusicSchoolContext и класс Db для подключения.

Models/ — классы-модели таблиц базы данных (созданы через Entity Framework).

Services/ — бизнес-логика (класс Session для авторизации, AppException для ошибок).

Views/ — файлы интерфейса Avalonia (XAML-разметка и код C#).

База данных и SQL-файлы
Для развертывания базы данных используется SQL Server Management Studio (SSMS).

Создайте пустую базу данных music_school.

Выполните скрипт из папки database (файл со структурой таблиц и тестовыми данными).

Основные таблицы: roles, users, students, teachers, categories, programs, groups, orders, order_items.

Настройка connection.txt
В корневой папке проекта находится файл connection.txt. В нем хранится строка подключения к вашей базе данных.
Пример содержимого:

text
Server=(localdb)\MSSQLLocalDB;Database=music_school;Trusted_Connection=True;Encrypt=True;TrustServerCertificate=True;Connect Timeout=5
Если вы запускаете проект на другом компьютере, измените значение Server= на актуальное имя вашего SQL-сервера.

Команды запуска
Клонируйте репозиторий на локальный диск.

Откройте решение MusicSchool.sln в Visual Studio.

Убедитесь, что файл connection.txt настроен верно.

Нажмите F5 для сборки и запуска проекта.
